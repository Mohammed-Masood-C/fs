# fs v2.0.0

fs can now run your folders in the background and manage them, Docker-style.
This is a major release with breaking changes. Read **Breaking changes**
before upgrading.

## Breaking changes

- **Windows only.** There are no macOS or Linux builds any more. Keep using
  the latest v1 release on those systems.
- **New commands take priority over folder names.** `start`, `stop`, `ps` and
  `logs` are now commands, so `fs start` no longer serves a folder called
  `start`. To serve such a folder, write it as a path: `fs .\start`.

## What's new

- **Background services.** Run as many folders as you like in the background,
  each on its own port, without keeping a terminal open for each. They keep
  running after you close the terminal.

  ```powershell
  fs start -p 8080 C:\www                 # or: fs -d -p 8080 C:\www
  fs start -p 8081 --auth me:secret D:\shared
  fs start                                # serves your default folder
  ```

- **`fs ps`** lists everything that's running, in the foreground or in the
  background: ID, folder, address, login, whether index files are served,
  mode, process ID and status.

  ```
  ID   FOLDER      URL                      LOGIN       INDEX   MODE         PID     STATUS
  1    C:\www      https://localhost:8080   -           on      background   10432   Up 5m
  2    D:\shared   https://localhost:8081   me:secret   on      background   11876   Up 12s
  ```

- **`fs stop`** stops a service by ID (`fs stop 2`), several at once
  (`fs stop 1 3`), or everything (`fs stop`). Services finish their open
  downloads before shutting down. IDs start at 1 and count up, and start at 1
  again once nothing is running.
- **`fs logs <id>`** shows a background service's log: startup, warnings and
  errors, plus every request if it was started with `--verbose`. Add `-f` to
  keep following it, which ends by itself when the service stops.
- **Self-cleaning.** Logs are deleted when a service stops. Services that ended
  without `fs stop`, for example when Windows shut down, are cleaned up the
  next time you use fs.
- **Clearer terminal output.** The startup screen, `fs start`, `fs ps` and
  `fs stop` have a tidier layout with colors. The startup screen now also shows
  the login, index mode and logging level.

## Download

| System | File |
| --- | --- |
| Windows (most PCs) | `fs-v2.0.0-windows-amd64.exe` |
| Windows on ARM | `fs-v2.0.0-windows-arm64.exe` |

Rename it to `fs.exe` and put it in a folder on your PATH. There is nothing to
install. `checksums.txt` lets you verify the download.

## Upgrading from v1

Close any running fs, then replace `fs.exe`. Your default folder and
certificate are kept, so browsers that already trust the certificate keep
working. All options from v1 still work the same way.
