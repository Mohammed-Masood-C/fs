# fs v1.0.0

The first release of **fs**: serve any folder as a website, or share it with
your network, with a single command.

```sh
fs C:\www
```

## Download

Pick the file for your system below, under **Assets**:

| System | File |
| --- | --- |
| Windows (most PCs) | `fs-v1.0.0-windows-amd64.exe` |
| Windows on ARM | `fs-v1.0.0-windows-arm64.exe` |
| macOS (Apple Silicon) | `fs-v1.0.0-darwin-arm64` |
| macOS (Intel) | `fs-v1.0.0-darwin-amd64` |
| Linux (x86-64) | `fs-v1.0.0-linux-amd64` |
| Linux (ARM64, e.g. Raspberry Pi 4/5) | `fs-v1.0.0-linux-arm64` |

Rename it to `fs` (`fs.exe` on Windows). There is nothing to install. On
macOS and Linux, make it executable first: `chmod +x fs`.
`checksums.txt` lets you verify the download.

## Highlights

- **Website hosting.** Folders with an `index.html` are served as websites,
  with the right file types for HTML, CSS, JavaScript, fonts, images and video.
  Refresh to see changes.
- **File explorer.** Browse folders, sort by name, size or date, filter by
  typing, and download files. Whole folders download as a ZIP.
- **Video and large files.** Videos can be seeked, and interrupted downloads
  resume.
- **HTTPS out of the box.** fs creates its own certificate on first start and
  redirects `http://` to `https://` automatically.
- **Network sharing.** fs prints the addresses other devices on your network
  can use.
- **Password protection.** `--auth user:pass` puts the server behind a login.
- **Cross-origin access.** Web apps on other ports or sites can load your files.
- **Only the folder you choose.** Nothing outside it can be reached. Visitors
  can view and download, but never upload or change anything.

## Usage

```
fs [options] <folder>

  -p, --port <port>      port to use (default 80)
      --host <address>   only listen on this address, e.g. 127.0.0.1
      --no-index         always show the file explorer
      --auth <user:pass> require a username and password
      --verbose          log every request
  -v, --version          show the version
  -h, --help             show help
```

## Good to know

- **Browser warning on first visit.** This is expected, because the certificate
  is self-signed. Click **Advanced → Continue**, or trust it once on Windows:
  `certutil -user -addstore Root "%AppData%\fs\cert.pem"`
- **Static files only.** PHP and other server-side code is not run, and there is
  no database. `.php` files are downloaded as plain text.
- **No auto-reload.** Refresh the page after editing a file.
- **Everything in the folder is visible**, including hidden files. Use `--auth`
  for anything private.
