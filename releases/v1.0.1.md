# fs v1.0.1

## What's new

- **Folder sizes in the file explorer.** The Size column now shows the total
  size of each folder, including everything in its sub-folders. Pages still
  open instantly: sizes fill in a moment later. Hover over a size to see the
  exact number of bytes and files.

## Download

Pick the file for your system below, under **Assets**:

| System | File |
| --- | --- |
| Windows (most PCs) | `fs-v1.0.1-windows-amd64.exe` |
| Windows on ARM | `fs-v1.0.1-windows-arm64.exe` |
| macOS (Apple Silicon) | `fs-v1.0.1-darwin-arm64` |
| macOS (Intel) | `fs-v1.0.1-darwin-amd64` |
| Linux (x86-64) | `fs-v1.0.1-linux-amd64` |
| Linux (ARM64, e.g. Raspberry Pi 4/5) | `fs-v1.0.1-linux-arm64` |

Rename it to `fs` (`fs.exe` on Windows). There is nothing to install. On
macOS and Linux, make it executable first: `chmod +x fs`.
`checksums.txt` lets you verify the download.

Upgrading from v1.0.0? Just replace the old file. The certificate fs created
is kept, so browsers that already trust it keep working.
