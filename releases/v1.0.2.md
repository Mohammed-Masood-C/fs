# fs v1.0.2

## What's new

- **Default folder.** Set the folder you serve most often once, and then just
  run `fs`:

  ```sh
  fs --set-default-path C:\www
  fs                      # serves C:\www
  fs D:\other             # a folder you pass still takes priority
  ```

  Run `--set-default-path` again at any time to change it. If the default
  folder is later moved or deleted, fs tells you and shows how to set a new
  one.

## Download

Pick the file for your system below, under **Assets**:

| System | File |
| --- | --- |
| Windows (most PCs) | `fs-v1.0.2-windows-amd64.exe` |
| Windows on ARM | `fs-v1.0.2-windows-arm64.exe` |
| macOS (Apple Silicon) | `fs-v1.0.2-darwin-arm64` |
| macOS (Intel) | `fs-v1.0.2-darwin-amd64` |
| Linux (x86-64) | `fs-v1.0.2-linux-amd64` |
| Linux (ARM64, e.g. Raspberry Pi 4/5) | `fs-v1.0.2-linux-arm64` |

Rename it to `fs` (`fs.exe` on Windows). There is nothing to install. On
macOS and Linux, make it executable first: `chmod +x fs`.
`checksums.txt` lets you verify the download.

Upgrading? Just replace the old file. The certificate fs created is kept, so
browsers that already trust it keep working.
