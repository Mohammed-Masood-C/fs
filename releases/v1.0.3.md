# fs v1.0.3

## What's new

- **Folder and file counts.** The file explorer has two new columns,
  **Folders** and **Files**, showing how many sub-folders and files each
  folder contains, at any depth. Like folder sizes, they fill in a moment after
  the page opens. On small screens the columns are hidden to save space.

## Download

Pick the file for your system below, under **Assets**:

| System | File |
| --- | --- |
| Windows (most PCs) | `fs-v1.0.3-windows-amd64.exe` |
| Windows on ARM | `fs-v1.0.3-windows-arm64.exe` |
| macOS (Apple Silicon) | `fs-v1.0.3-darwin-arm64` |
| macOS (Intel) | `fs-v1.0.3-darwin-amd64` |
| Linux (x86-64) | `fs-v1.0.3-linux-amd64` |
| Linux (ARM64, e.g. Raspberry Pi 4/5) | `fs-v1.0.3-linux-arm64` |

Rename it to `fs` (`fs.exe` on Windows). There is nothing to install. On
macOS and Linux, make it executable first: `chmod +x fs`.
`checksums.txt` lets you verify the download.

Upgrading? Just replace the old file. Your default folder and certificate are
kept.
